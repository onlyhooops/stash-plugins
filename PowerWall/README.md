# PowerWall

Stash 原生风格的**砌墙视图**插件：在图片/短片列表页提供列优先递补布局、等比例缩放的墙视图，支持无限滚动与内置 Lightbox。

## 功能

- **砌墙布局**：列优先递补（最短列放置），缩略图等比例缩放、无剪裁无拉伸
- **6 档缩放**：滑块调节列宽（160～640px），仅滑块无文字
- **布局预设**：无缝 / 紧凑 / 标准 / 宽松（边距、行距、列距；无缝为无间距拼接）
- **无限滚动**：触底自动加载下一页
- **内置 Lightbox**：点击图片全屏浏览，支持缩放、拖拽、1:1、左右切换与向下拖拽关闭；左上角无底色信息栏显示图片名、计数器及图库（文件夹）名（可点击跳转）；右下角竖向缩放按钮；进入/退出时无布局偏移
- **返回顶部**：右下角浮动 TOP 按钮，滚动一定距离后显示，点击平滑回到顶部
- **首页**：工具栏「首页」一键清除筛选/随机/图库参数并恢复默认排序，随览、随阅或筛选之后无需刷新浏览器；「首页 / 随览 / 随阅」三个按钮各自只在**对应模式生效时**点亮（首页=当前为默认视图，随览=随机排序，随阅=随机图库），给出一致的模式指示
- **视图模式**：可切换回 Stash 原生列表（「原始」），该选择按图片页/短片页分别记忆，刷新与换页后保持；原始视图右下角常驻功能唯一的「墙视图」按钮作为返回入口
- **卡片角标**：分辨率在左上、时长在右下（右上角留给其它插件），均为毛玻璃轻着色（不再使用实色块）
- **工具栏悬浮固定**：固定于系统顶部导航栏下沿，滚动时位置不变；高度与系统顶栏对齐，但底色刻意更深（`#202b33` + 上沿暗线 + 下沿投影），视觉上与系统顶栏明确区分、不融为一体；`z-index: 1030` 与原生顶栏同层；图标统一为 Font Awesome 6 Solid（与 Stash 原生导航同一图标集），内联 SVG、按原始比例缩放
- **工具栏自适应**：单行不换行；已加载/总数简写（如 1.7M）；宽度足够时按钮显示图标+文字，变窄时仅图标；关键词通过筛选面板使用（工具栏无搜索框以减轻性能影响）
- **随阅**：随机打开一个图库内的全部图片/视频，在当前砌墙中展示（仅图片页，与随览不同：随览完全随机，随阅随机选图库）
- **视频悬停**：短片卡片悬停时预播预览片段
- **筛选**：关键词、路径、排序、标签/演员/工作室
- **协作**：`enhancedWallItemAdded` 事件，兼容 FavoriteHeart 等插件
- **作用范围**：仅 `/images`、`/scenes` 列表；小屏/触屏不启用

## 安装

将 `PowerWall` 目录放入 Stash 的 `plugins` 目录，在 **设置 → Plugins** 中重载插件。

## 兼容性

- **Stash**：需支持 UI 插件的版本（通常 v0.25+）
- **作用页面**：`/images` 与 `/scenes` 列表页
- **不作用**：`/tags`、`/galleries`、`/performers`、`/studios`、`/movies`、`/markers` 及详情页等

## 功能边界

1. 仅替换 `/images`、`/scenes` 根列表页的墙/网格内容，不影响其它页面；切到「原始」视图时不替换任何内容，原生列表原样保留，只在右下角追加一个「墙视图」按钮
2. 使用 `PluginApi.Event` 监听 `stash:location` 实现路由感知；无 PluginApi 时使用 history API 备选
3. 使用 Stash 标准 `/graphql` 端点，不调用非公开接口
4. 样式与 DOM 均限定在 `.power-wall-*` 命名空间内
5. 离开列表页时完整卸载并清理 DOM、事件、全局状态

## URL 筛选参数

| 参数 | 说明 |
|------|------|
| `q` | 关键词搜索 |
| `path` | 路径包含过滤（支持筛选面板选择） |
| `tags` | 标签 ID，逗号分隔 |
| `performers` | 演员 ID，逗号分隔 |
| `studios` | 工作室 ID，逗号分隔 |
| `galleries` | 图库 ID（仅图片页） |
| `sortby` | 排序字段（created_at / date / title / rating100 / updated_at / random_&lt;seed&gt;） |
| `sortdir` | 排序方向，`ASC` 或 `DESC` |

## 配置

在列表页工具栏点击「设置」（滑杆图标）配置，保存至 `localStorage`（键：`PowerWall_config`）。

### 布局预设

无缝 / 紧凑 / 标准 / 宽松，分别调节边距、行距、列距。无缝模式下图片之间无行距、列距与边距，实现无缝拼接。

### 功能开关

| 项 | 说明 |
|----|------|
| 图片列表启用 | 是否在 `/images` 启用砌墙 |
| 短片列表启用 | 是否在 `/scenes` 启用砌墙 |
| 内置 lightbox | 点击图片在内置 lightbox 浏览 |
| 高级 | 每页数量（12～120）、调试模式 |
| 视图模式 | 非面板开关：由工具栏「原始」/ 原始视图「墙视图」切换，记忆在 `viewModeImages` / `viewModeScenes` |

### 视图模式与首页

- **原始视图**：点工具栏「原始」切回 Stash 原生列表。该选择会写入配置并**按页面类型分别记忆**（图片页与短片页互不影响），因此刷新、翻页、切换路由后都会保持。原始视图下插件不渲染任何工具栏，回到砌墙的唯一入口是右下角常驻的「墙视图」按钮。
- **首页**：点工具栏「首页」会删除 URL 上的筛选/排序/翻页/图库参数（`q`、`sortby`、`sortdir`、`page`、`tags`、`performers`、`studios`、`galleries` 及其 `*_ids` 变体）并把默认排序恢复为 `created_at DESC`。只清理插件自己管理的参数，不影响其它插件或 Stash 自身写在 URL 上的参数。
- **模式指示**：三个模式按钮的亮灭严格对应各自是否生效——默认视图只有「首页」亮；点了「随览」（`sortby=random_*`）只有「随览」亮；点了「随阅」（`galleries=*`）只有「随阅」亮；点「首页」后回到只有「首页」亮。若只应用了筛选（既非首页也非随机），三个都不亮，符合「只有被启用才点亮」的语义。`aria-pressed` 与视觉状态同步。
- 面板中的「恢复默认」会重置整份配置，因此视图模式也会一并回到墙视图。

### 筛选

点击工具栏「筛选」（漏斗图标）打开筛选面板，支持关键词、路径、排序、标签/演员/工作室多选，与 URL 同步。

## 性能与鲁棒性

- **无限滚动**：IntersectionObserver，无 scroll 轮询；回调按整批 entry 判定 `isIntersecting`，并在每页加载结束后做一次带预算的续载检查（避免交叉状态不再变化导致的静默停载）
- **布局**：ResizeObserver + debounce；DOM 逐张插入（每帧 1 项，一张一张依次上墙）、单次高度更新；标题排序在整批插入结束后只做一次全量重排
- **请求**：GraphQL 支持 AbortSignal（刷新/离开时取消）、30s 超时
- **配置**：缓存、localStorage 读写异常处理、zoomIndex/itemsPerPage 范围校验；缩放滑块拖动期间只做 rAF 合并重排，松手后才写入 localStorage
- **Lightbox**：复用 overlay 时正确更新 prev/next 索引，键盘与鼠标事件按需绑定/解绑
- **路由**：PluginApi.Event 或 history fallback，离开时完整卸载
- **主题适配**：Stash（Bootstrap 4.6）不提供 CSS 自定义属性，插件因此在 CSS 顶部把 Blueprint 深色主题的真实取值集中定义一次（宿主若提供同名变量则优先跟随），面板/表单控件/角标/滚动条/焦点环都取这些值；砌墙单格底色与 Stash 原生 `wall-item-media` 一致（纯黑）。悬浮工具栏使用比系统顶栏更深的 `#202b33`（近不透明）并带投影，与顶栏明确区分；返回顶部按钮保持深色半透明底

## 技术实现

- **规范**：遵循 [Stash UI Plugin API](https://docs.stashapp.cc/in-app-manual/plugins/uipluginapi/)
- **数据**：GraphQL `findImages` / `findScenes` / `findFolders` 等
- **路由**：`PluginApi.Event` 监听 `stash:location`，无 `PluginApi.patch` 避免 React 冲突

### 1.9.0

**修复**

- **无限滚动静默停载**：IntersectionObserver 回调原先只读 `entries[0]`。在 `unobserve/observe` 之后，同一个 target 可能在一个回调里投递多条 entry（顺序不保证），一旦读到过期的 `isIntersecting: false` 就直接返回；而此时 observer 已缓存 `true`，交叉状态不再变化 → 再也不投递回调，墙**永久停止加载**，且界面既不显示"加载中"也不显示"已加载全部"，只能靠大幅回滚或刷新恢复。改为按整批判定 `entries.some(isIntersecting)`，并在每页加载结束后补一次带预算的续载检查（每页最多一次、一轮最多自动续 3 页）作为兜底
- **缩放滑块卡顿**：`input` 原先每个事件都同步写 localStorage 并全量重排。实测（400 项）40 个事件阻塞主线程约 1s（单个 968ms 长任务）。现在 `input` 只更新内存配置 + rAF 合并后重排一次，`change`（松手）时才落盘一次；拖动中仍实时生效，刷新后仍能恢复
- **标题排序开销**：`applyTitleSort()` 原先在分块插入循环内调用，每 16 项就把整墙排序 + DocumentFragment 重挂 + 全量重排一次。实测每个 40 项页触发 **5 次整墙重挂**（每次搬动 400–520 个节点）。现移到整批插入结束后只做一次（实测同页降为 1 次）
- **关闭「图片列表启用」（或短片列表启用）后列表空白**：`html` 上的 `power-wall-preload` 会残留，原生墙/网格仍被 `display:none` 隐藏。现在无适用页面类型时会完整清理
- **卡片 meta 转义**：演员名、工作室名补 `escapeHtml`（此前仅标题做了转义）
- **面板配色与主题不一致**：Stash 使用 Bootstrap 4.6 且**不输出任何 CSS 自定义属性**（`_theme.scss` 里全是 SCSS 变量），所以插件里 `var(--card-bg, …)` / `var(--text-muted, …)` 之类**全部落在兜底值上**——面板底色变成偏紫的 `#1a1a2e`、表单控件近黑 `#0d0d12`、次要文字 `#888`。现在把这些取值集中定义一次，并采用 Stash Blueprint 深色的实际值：`$card-bg #30404d`、`$body-bg #202b33`、`$secondary #394b59`、`$text-color #f5f8fa`、`$text-muted #bfccd6`、边框 `#414c53`；宿主若提供同名变量则优先跟随。面板底色现与 Stash 自身 `.modal-*` 完全一致（实测逐像素同为 `#30404d`）。同时砌墙单格底色改为纯黑，与 Stash 原生 `.wall-item-media` 一致

**界面**

- **图标体系**：工具栏、面板标题、面板按钮、卡片 meta、加载状态中的 emoji 全部替换为内联 SVG（16×16 / meta 12×12，`stroke: currentColor`），不再出现彩色 emoji 与单色字形混排
- **强调色统一**：排序按钮激活态由硬编码紫色改为与缩放滑块相同的 `--primary`，同一个工具栏内不再出现两种强调色
- **卡片角标**：分辨率在左上、时长在**右下**（原先把两者都挤在左上）；时长放右下是为了把右上角让给其它插件构建的元素，避免互相遮挡；两者均为毛玻璃轻着色（`blur` + 轻底色 + 细边 + text-shadow），4K 仅保留极轻色相提示；hover 时卡片信息层的胶囊会自动为右下角标让出空间；补齐此前缺失的 `.resolution-4k` / `.resolution-hd` / `.duration` 样式
- **卡片信息层**：hover 渐变加深加高，标题与 meta 补 `text-shadow`，meta 胶囊改深色半透明（亮图/暗图均可读），并补上此前缺失的淡入过渡
- **Lightbox**：标题栏**完全取消底衬**（深色遮罩、毛玻璃带都不再有），文件名与文件夹（图库）名只靠双层 `text-shadow` 保证压在亮图上仍可读；文件夹名不再有底色块与边框；关闭按钮改 SVG 图标
- **新增「首页」按钮**：一键清除筛选/随机/图库参数并恢复默认排序，随览、随阅、筛选之后无需刷新浏览器
- **模式指示修正**：「首页 / 随览 / 随阅」三个按钮此前把“是否离开默认视图”错误地显示在「首页」上（点随览、随阅会把「首页」点亮）。现在各自只在对应模式生效时点亮：默认视图→首页亮；随览→随览亮；随阅→随阅亮；仅筛选时三个都不亮。`aria-pressed` 同步，首屏即显示正确状态
- **「原始」视图状态持久化**：选择会按图片页/短片页分别记忆，刷新、换页、路由切换后保持；原始视图右下角新增常驻、功能唯一的「墙视图」按钮作为唯一返回入口（插件在原始视图不渲染工具栏，故该入口必须常驻可达）
- **设置/筛选面板对齐设计语言**：标题加图标、关闭与底部按钮改为 SVG 图标+文字、复选框尺寸与强调色在两个面板统一、`高级` 折叠改用 SVG chevron 并旋转、面板内滚动条主题化、焦点环可见（不再 `outline: none`）、圆角统一为 6px、按钮与主按钮 hover 改由主题色推导
